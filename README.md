# NAVA Private Yachts — версия для GitHub Pages

Это полностью статический сайт. Для работы не нужны Node.js, npm, сервер, база данных или платный хостинг.

## Публикация

1. Создайте новый публичный репозиторий на GitHub.com.
2. Загрузите в корень репозитория `index.html`, `README.md` и папку `assets`.
3. Откройте `Settings → Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Укажите ветку `main` и папку `/ (root)`, затем нажмите `Save`.

Через несколько минут сайт будет доступен по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

Все пути к изображениям относительные, поэтому сайт работает и в корне домена, и в подпапке репозитория GitHub Pages.

## Что работает без сервера

- интерактивные остановки и программы маршрутов по дням;
- галереи шести моделей яхт: экстерьер, салон и мастер-каюта;
- подробные характеристики и ссылки на официальные каталоги верфей;
- сравнение двух или трёх яхт в одной таблице;
- выбор маршрута и яхты в форме заявки.

Фотографии новых моделей в `assets/fleet-v2` — оригинальные AI-визуализации NAVA, созданные по конструктивным и интерьерным особенностям реальных серий. Они не являются официальными фотографиями конкретных корпусов. Перед коммерческим запуском наличие и комплектацию каждой яхты необходимо подтвердить.

## Важно о форме

GitHub Pages раздаёт только статические файлы и сам не отправляет заявки. Сейчас форма показывает подтверждение в браузере. Для реального приёма заявок можно позднее подключить Formspree, Telegram-бота или другую внешнюю форму.
